# Examen Práctico Hito 3 — TQA

Repositorio correspondiente al **Examen Práctico del Hito 3** de la materia Testing & Quality Assurance de UNIFRANZ.

El proyecto reúne pruebas funcionales realizadas en [SauceDemo](https://www.saucedemo.com/), análisis de código Python, escenarios Gherkin y documentación de defectos.

## Contenido del proyecto

- **Caja Negra:** Diseño y ejecución de 5 casos de prueba funcionales.
- **Caja Blanca:** Análisis de una función Python y sus criterios de cobertura.
- **Gherkin:** Escenarios de inicio de sesión exitoso y fallido.
- **Bug Report:** Documentación de un defecto visual reproducible.
- **Evidencias:** Capturas de las pruebas realizadas.
